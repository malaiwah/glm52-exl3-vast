Concurrency ceiling. It defaults to 8 and not 32 because decode runs m = MAX_NUM_SEQS x (1 + MTP_TOKENS) query tokens per step, and 8 x 4 = 32 exactly fills the default CUDA-graph capture and EXL3 trellis windows.
